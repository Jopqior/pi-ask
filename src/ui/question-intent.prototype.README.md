# THROWAWAY: question intent + Review

[验证逐题操作与 Review 统一确认](https://github.com/Jopqior/pi-ask/issues/4)的独立终端实验。
验证逐题 Elaborate 与统一 Review 是否清楚，以及选择和前进的键盘操作是否符合预期。
**用户已实际复核选择、前进、自定义填写和行内重编辑。原型不是生产实现。**

```bash
# 在 prototype/question-intent-review 分支的工作树根目录运行
pnpm prototype:intent
```

需要支持原生 TypeScript 的 Node 和现有依赖，不需要新依赖。
工作树可复用主仓库的 `node_modules` 符号链接。不是 `pi -e` 扩展入口。

## 操作规则

| 操作 | 单选 / preview | 多选 |
| --- | --- | --- |
| 普通选项数字 | 选中并停留，重复不取消 | 切换选中并停留 |
| 普通选项 Space | 切换选中并停留 | 切换选中并停留 |
| 普通选项 Enter | 选择当前高亮项并前进 | 前进，不改变答案 |
| 自定义编辑器 Enter | 保存并停留，焦点落在自定义行 | 同左 |
| 已有非空内容的自定义行 Enter | 确认自定义答案并前进 | 前进，保留当前选择 |
| 空白自定义行 Enter | 打开编辑器 | 同左 |
| e（非编辑题目页） | 独立切换 Elaborate 并停留 | 同左 |

- Up/Down 高亮选项；Tab/Right 下一页，Shift+Tab/Left 上一页，含 Review。
- 空白自定义行：数字或上下键到达时直接打开单行 Input；Enter/Space 也可打开。
- 已有文本的自定义行：上下键只定位；数字/Space 负责选择或切换，不重新编辑。只有焦点在该行时，才显示并响应 c 重新编辑。
- 其他选项行及 Review 不显示 c 提示，c 不触发操作；编辑器中的 c 是普通文字。
- Shift+N 编辑题目附注，n 编辑高亮选项附注。
- 编辑中 Esc 保存并关闭；自定义内容保存后焦点落在自定义行。e 是普通文本，箭头由 Input 处理。
- Backspace/Delete（非编辑）清空本题答案，保留附注与 Elaborate；Space 可取消普通已选项。
- Review：Up/Down 在题目行、Submit、Cancel 间移动，Enter 激活。无数字快捷键、无全局 Elaborate。
- PgUp/PgDn 滚动上下文（非编辑），可查看长附注。
- Cancel / Esc：有答案、附注或 Elaborate 时需再次确认。
- Ctrl+C 直接退出；提交/取消停在本地结果检查页。
- **F3 立即清空所有状态及草稿，循环加载下一个 fixture**，无保存或恢复。

Elaborate 默认关闭，选择、保存、Enter 或导航不改变它，可用 e 显式取消。
开启后答案是暂定作答，不是最终决定。每题必须有选项或非空自定义答案；
只有附注或开关不能满足提交条件。解释请求可写成非空自定义答案并开启 Elaborate。
未答题即使开启 Elaborate 仍显示 UNANSWERED，不显示为已完成。

## 操作复核与反馈模板

启动在 Q1（已选 Local），不必切换模式：

1. 普通选项行按 c：不打开编辑器，也没有 c 提示。
2. 按 3，或 Down 两次到空白自定义行：直接进入填写。输入文本后 Enter 保存，停在自定义行。
3. Up 离开自定义行，按 c 无效；Down 返回已有内容的自定义行，不自动编辑，此时才显示 c。
4. 按 c 编辑，输入字符 c 应作为文字；Enter 保存，再 Enter 确认并前进，保留文字和 Elaborate。
5. 返回 Q1，数字 3 到已有文本的自定义行，只选中并停留，不打开编辑器。

同时检查：单选数字重复不取消，Space 切换并停留，Enter 选择并前进。
多选的自定义文本可以取消选中而保留草稿，数字/Space 只切换选中状态，不打开编辑器。

反馈：

- 其他行 c 无效且无提示：符合 / 不符合。
- 空白行自动填写、已有内容只定位、行内 c 重编辑：符合 / 不符合。
- 保存与确认前进保留文字和 Elaborate：符合 / 不符合。
- 若不符合：按键顺序 → 实际结果 → 期望结果。

## 其他场景

F3 循环 1 → 2 → 3 → 4 → 1，每次重置。

1. 混合：Q1 普通作答、Q2 暂定作答、Q3 未答且 Elaborate 开启。
   Review 提交应停在 Review，列出 Q3 并高亮；Enter 回题补答。
2. 全空：只开 e 或只填附注仍是未答，不能成功提交。
3. 附注：Q1 含题目附注、已选 Local 附注、未选 Cloud 附注。切换答案或意图不丢附注。
4. 解释请求：Q1 有自定义请求和 Elaborate，无普通选项；清空后恢复未答。

## 实验边界与验证记录

只导入 pi-tui 和 Node URL API，无模型、网络、个人配置、通知、持久化或真实工具结果。
不实现自动提交、配置迁移、replay、resume、remote 或 /answer 兼容规则。
结果页只供本地检查，取消后保留的是已丢弃内容的实验快照，不发送任何内容。
正式键位与迁移交兼容规则票，不因原型用 e 或 c 就自动成为产品默认值。

为便于检查，普通作答也显示全部附注。单选改为普通选项会替换自定义答案；多选可并存。
使用单行 Input 和简化预览；没有复刻生产的全部编辑器和快捷键。
真实桌面 IME 与跨终端兼容性未专项验证。

用户已实际确认逐题意图状态、Review 内容及补答路径，以及数字、Space、Enter、自定义填写、
保存、确认前进与行内 c 重编辑路径。
开发烟测覆盖上下文键位、空白行自动编辑、已有文本选择、多选草稿和 40/80/120 列渲染。
当前源码保留在独立原型分支，不合入 main。
